# Adversarial and method-bias audit

The supplied *Philosophical Depth and Deficit Adversarial Analysis* is treated as a design critique, not as authority to diagnose people. This implementation preserves its central separations: response adequacy, inquiry transitions and latent capacity are different constructs; length, concept counts, doubt counts and revisions are not depth; inability, unwillingness and lack of opportunity cannot be conflated.

| Failure mode | Implemented response | Remaining limitation |
|---|---|---|
| Doubt becomes falsity | Separate `doubted` set and four-valued commitment status | Grounds are authored annotations |
| Circular support proves itself | Least-fixed-point grounding rooted in accepted grounded propositions | Grounded means stipulated within this model |
| Contradiction licenses everything | No explosion rule; encoded conflicts stay local | Explicit strict rules can still carry controversial implications |
| Prose appears to be understood | Prose never enters deterministic parser | Structured entry costs effort and shapes responses |
| Confirmation invented | Outcomes default to unmeasured | Participant-declared outcome is not independent evidence |
| A method grades itself | Shared human rubric; no automatic success score | Raters need calibration and independent adjudication |
| Neutral control receives targeted feedback | Graphs hidden in rehearsal; neutral questions are non-systematic | Shared structured editor can itself prompt reasoning; estimate is incremental over that common interface |
| Assessment contamination | Distinct pre/intervention/post/delayed pools | Related Depth Map prompts are public; exposure must be controlled |
| Methods have own success metric | Eight common dimensions; fidelity separate | Rubric fairness is unvalidated, not guaranteed |
| Blindness claimed too strongly | Packet removes allocation fields; UI says local concealment only | Wording, source inspection and prior familiarity can reveal condition |
| Synthetic results mistaken for findings | Synthetic flag and explicit analysis banner | Researchers must preserve provenance when exporting |
| Person-level deficit inferred | No deficit label or universal proficiency output | Downstream misuse cannot be prevented solely by UI |

The 60 intervention items are balanced by domain and include explicit assumptions, opposing propositions, two objections and two hypotheses. This is a structural audit. Ethics and politics often have nonempirical normative bridges; the pragmatist prompt explicitly asks what evidence cannot settle. Logic items with strict rules may make formal contradictions easier to detect; domain-by-method interactions need empirical examination. Repeated graph shape makes software comparison simpler but narrows ecological validity.

Adversarial fixtures exercise circular rules, empty commitments, jointly accepted incompatibilities, arbitrary prose, invalid IDs, unmeasured outcomes, altered replay logs, premature follow-up, degenerate kappa and invalid AI intervention requests. Passing these checks establishes specified software behavior, not philosophical completeness or educational validity.
