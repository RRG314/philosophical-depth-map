# Expansion roadmap and release gates

1. **Content validation:** independent Cartesian, Platonic and Deweyan specialists review each protocol and ten intervention items per domain. Record contested interpretations and alternative encodings. Pilot cognitive interviews for all three assessment forms. Gate: documented revisions, not unanimous philosophical agreement.
2. **Measurement:** build evidence-bearing anchor examples and rater training; examine missing opportunities, ordinal reliability, dimensional structure, differential item functioning and form equivalence. Gate: a defensible interpretation/use argument; no universal depth ranking.
3. **Approved collection service:** institutional determination, consent/withdrawal/retention policy, authenticated enrollment and rater roles, server-authoritative allocation and budgets, encrypted storage, scoped exports and audit tests. Gate: independent security review and approved protocol. Current public rehearsal stays usable without this service.
4. **AI provider qualification:** pin a supported model snapshot; run all four prompts on adversarial inputs; inspect schema failures, latency, token limits and condition leakage. Record actual provider/model fingerprint if available; an alias is not an immutable version. Gate: live credentialed integration evidence. Mocked provider tests alone do not meet it.
5. **Confirmatory experiment:** preregister primary outcome, meaningful effect, sample size/power simulation, stratification, attrition handling, multiplicity and crossed participant/item analysis. Separate deterministic and AI implementation estimands. Gate: consented data and independent outcome ratings.
6. **Longer-term transfer:** fresh withheld items, delayed retention, alternative domains and dialogue budgets; examine interaction quality and harms without equating ideology with competence. Gate: replication before educational efficacy claims.
7. **Formal extensions:** explicit negation and richer rule semantics, alternative argumentation extensions, audited AGM operators and human-reviewed counterexample libraries. Keep new calculi versioned and maintain browser/Python parity. Do not silently reinterpret old traces.
8. **Accessibility and internationalization:** additional language versions reviewed for semantic equivalence, keyboard/screen-reader user testing and low-bandwidth modes. Wider philosophical coverage should involve scholarship from each tradition rather than replacing names in Western templates.
