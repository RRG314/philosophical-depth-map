# Philosophical Reasoning Lab integration plan

The existing Depth Map remains the exploration product. Reasoning Lab is an independently routed feature module, not additional conditional markup throughout the exploration game. Learn is a separate reading directory. Shared site navigation links them; data, XP and research outcomes do not mix.

1. Define versioned structured problem/action/trace contracts, protocol stages and limits. Implement the same bounded symbolic semantics in TypeScript and Python; test parity and counterexamples.
2. Author 60 intervention problems plus disjoint assessment forms across six domains. Record assumptions, objections, consequences, references and method-affordance caveats.
3. Build demonstration/comparison, structured dialogue, inspectable graph, local history and replay; separate concealed-condition experiment rehearsal with fixed budgets and seeded schedules.
4. Build blind packet export and rater workspace, independent general-reasoning and fidelity criteria, reliability and reproducible synthetic analyses. No agent self-ratings as outcomes.
5. Add four server-side model protocols under one locked model/parameter configuration, common input/output schema, provenance and fail-closed limits. Existing optional Worker handles transport; research collection stays disabled.
6. Add PostgreSQL migration, privacy/consent gates, literature/learning catalog, integration specification, browser tests and Pages release.

Acceptance: original game tests remain passing; four deterministic engines run offline from AI; Python parity, fixed budgets, assignment/replay, assessment separation and blind exports tested; rater inputs persist/export; Pages serves all new routes. LLM adapter tests use identified fixtures until credentials exist. Public experimental mode is a local rehearsal, not live enrollment; local client-side labels cannot guarantee allocation secrecy against source inspection.

Attachment implications: keep response quality, inquiry transitions and person-level inference distinct; no deficit labels, scalar depth ranking, answer-length rewards or forced revision. Permit suspension and premise rejection. Method fidelity is a separate manipulation check, never the primary reasoning outcome.
