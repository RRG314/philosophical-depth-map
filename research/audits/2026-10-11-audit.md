# Expedition and reasoning audit — 11 October 2026

This is an observed software test and editorial audit of the actual application. It is **not** a participant experiment, a finding of learning effectiveness, or evidence that any philosophical method is superior. No participant data were collected. Synthetic actions and mocked provider responses are identified below.

## Problems reproduced and corrected

| Finding | Evidence | Correction |
|---|---|---|
| Revision was rewarded more than justified retention | A regression test observed 13 XP after marking revision versus 10 for the same retained answer | 10 exploration points per distinct, nonblank exploration; neither position nor revision earns a bonus |
| Assessment responses and blank records could advance the game | Regression observed 10 points for an assessment-only fixture; the same old rule counted empty completions | Filter game milestones to nonblank exploration; assessment no longer adds newly discovered concepts |
| Recommended exploration could include assessment items | The recommendation function ranked the whole bank without filtering | Exclude assessment items from recommendations and optional ocean questions; the public practice assessment is still publicly available and is not an embargoed research instrument |
| Inconsistent depth metaphors | Old square-root XP regions did not correspond to equipment or physical water depth | One nine-stage threshold sequence shared by text progress and the expedition; ankle, waist, neck, surface snorkeling, 18 m scuba, 60 m technical equipment, 600 m submersible, 4,000 m deep-rated submersible and the Mariana grid (deepest sample 10,925 m) |
| The default AI token allowance could interrupt a full rehearsal | 40,000 units permanently reserved per call × 10 exhausted the 400,000 daily allowance before 12 intervention turns | Transactional reservation IDs and one-time settlement using validated provider usage; failed or unknown-usage calls retain their reservation. Tests complete 12 mocked turns and prohibit duplicate, negative, fractional and unknown-ID refunds |
| Invalid requests could consume quota before semantic checks | Unknown item IDs passed the previous shape/regex checks | Verify canonical items and Lab action/history consistency before allocation; malformed JSON returns 400 and oversized bodies 413 |
| Missing provider usage was treated as zero | Provider adapter used a zero default for absent accounting | Reject missing/invalid usage; do not release the reservation |
| Worked examples implied a single reasoning level | An example was shown as “Illustrative level 3” despite six separate dimensions | Display editorial examples without a global level, explain dimension-specific evaluation and legitimate disagreement; preserve underlying content/version history |
| Starting a game mission could overwrite an unfinished reflection | The common text start action replaces its active draft | Expedition explicitly offers resume or keep exploring; saved answers remain intact |

| Local deletion could be acknowledged before durable storage completed | Browser reload after clicking delete reproduced the old journal | Await queued writes and the reset write before showing success; the browser regression waits for acknowledgment then reloads |

The XP change recalculates engagement from existing answers. It does not delete or rewrite responses, ratings, question versions or the journal. Historical discovered concepts are retained rather than erased. They are no longer an XP input.

## Content findings

The reproducible script `python3 research/audits/content_audit.py` writes `2026-10-11-content-counts.json`.

- Depth Map: 160 unique prompts, 20 per each of eight domains; 16 public assessment items, 160 concepts, 1,325 graph edges. Eight keyed multiple-choice items distribute their answer keys 3/3/2 across positions, so there is no “always choose the first answer” defect.
- Lab: 60 intervention items, six each for pre, post and delayed forms. All 78 items have four propositions and the same designated grounded proposition (`p1`). There are 73 defeasible arguments and five strict arguments. No authored objection is marked as a refutation when admitted.
- 152 Depth Map items contain two editorial examples; eight contain three. Most example pairs contrast a weak answer with one qualified answer. That is not a balanced sample of competing philosophical positions. The UI fix avoids overstating these examples as validated scores; independent viewpoint-diversity review remains necessary.
- Balanced domain counts do **not** establish equivalent difficulty, equal reading load, equal method affordances, cultural representation or psychometric validity. The bank predominantly uses familiar academic analytic dilemmas. Existing broader learning links do not repair sampling bias in an experimental item bank.

Targeted editorial probes:

| Item | Probe and assessment |
|---|---|
| ethics-08, future people | The explanation assumes morally relevant future interests. Non-identity and person-affecting objections remain live. A defensible rejection of that assumption must not be treated as a poor answer merely for its conclusion. |
| epistemology-05, useful false belief | Separating practical from epistemic rationality is helpful. “Knowingly retaining belief” itself needs scrutiny: deliberate acceptance or make-believe may be different from belief. |
| logic-03, true conclusion | A true conclusion does not establish validity or soundness. This is a legitimate logical distinction; it must not be diluted into “all answers are equally correct.” |
| metaphysics-05, open future | First-person uncertainty does not entail objective indeterminacy. This rebuts that inference, not every libertarian account of agency. |
| mind-10, hidden motives | A hidden influence alone does not settle responsibility. The prompt leaves a causal-strength and control criterion to be supplied. |
| politics-08, civil disobedience | Public reasons and proportionality are contestable criteria, not necessary truths. An alternative account needs reasons, not conformity to the sample. |
| aesthetics-06, interpretation | The sample leans toward plural constraints on interpretation. Intentionalist and anti-intentionalist responses deserve separate good examples. |
| science-06, unobservables | Predictive success supports an abductive argument, not deductive entailment. Empirical adequacy and realism must remain distinguishable. |

These are editorial analyses, not independent expert ratings. No paper citation or link check by itself validates the item interpretations.

## Logic and backend boundaries

The shared engines use positive closure over **authored** strict rules with local conflicts; they do not parse arbitrary philosophical prose. “Refuted” means rejected or defeated relative to the supplied encoding, not externally established falsehood. Grounding is stipulated, not epistemically proved. A contradiction does not cause explosion. Defeasible bridges do not derive truth. Tests cover circular support, unmeasured outcomes, invalid identifiers, replay tampering and structured counterexamples.

The repeated four-node structure is a real ecological-validity gap. Refuting objections and varied multistep arguments need a separately versioned, independently reviewed bank before a broad comparison of methods. Silently replacing the experimental bank during this graphics release would invalidate existing logs. The current bank and protocols therefore remain frozen; adversarial synthetic tests exercise additional states without changing them.

Backend coverage includes Worker request validation and fail-closed routes, provider injection boundaries, one-time quota settlement, private PostgreSQL schema/collector gates through CI, and refusal of unauthorized research collection. Mock transport tests establish request/accounting behavior; they do not establish live-model philosophical quality, prompt-injection immunity, production capacity, or security certification. CORS is not authentication. The optional AI demo remains public but bounded when configured; private research enrollment stays disabled.

## Implemented game and return loop

The expedition is a Three.js scene with a modeled diver, mask, fins, tanks, hoses, a research submersible, waterline tint, shadows, reef life and optional anchored reading stations. Keyboard and touch movement, picking, fullscreen, habitat selection and a text-equivalent interface are implemented. WebGL failure falls back to the same questions. The renderer loads only when the expedition opens and disposes its resources when it closes. Eleven Sketchfab assets are bundled under CC BY 4.0, including a textured diver, spherical research submersible, scanned reef, fish, shark, jellyfish, bobtail squid, blue whale, sperm whale, anglerfish and dumbo octopus. See `public/assets/ocean/ATTRIBUTION.md` and its hashed manifest. Character meshes and authored animations are retained; reef geometry and textures are optimized. A second coral collection was rejected after observed rendering and performance problems. Precise transformed bounds fixed floating reef placement. Asset-loading failures remain visible rather than silently substituting primitive animals.

Text answers and game progress come from the same local journal. Habitat tours do not fabricate achievement. Any question remains accessible in the text explorer; milestones unlock an expedition itinerary rather than intellectual permission. Saved inquiries and three-day revisits provide return activities; repeated visits do not inflate unique-question progress. Three days is a product heuristic, not an experimentally established spacing optimum. The game does not require daily attendance or punish broken streaks.

Depth readouts now follow the player’s vertical coordinate in metres. The Mariana destination uses a documented GEBCO grid without vertical exaggeration; other habitats remain authored scenes. Ambient fill and approximate water scattering support legibility; this is not a physically validated light-transport simulation. NOAA distinguishes the sunlit upper ocean, the 200–1,000 m twilight region, and the absence of sunlight below roughly 1,000 m. Equipment progression is representational, not a training, certification or dive-planning system. [NOAA: light travel](https://oceanservice.noaa.gov/facts/light_travel.html); [NOAA: submersibles](https://oceanexplorer.noaa.gov/technology/subs/).

Gamification research supplies a design rationale, not a prediction for this application. A meta-analysis reports heterogeneous effects across contexts; pooling such interventions cannot establish that this particular ocean increases reasoning quality or return visits. [Li, Ma & Shi (2023), Frontiers in Psychology](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2023.1253549/full).

## What a real empirical study still needs

1. Conduct consented usability sessions with both keyboard and touch users, including assistive-technology users. Observe finding an optional question, switching views, completing a reflection, returning to the correct habitat, and distinguishing exploration progress from ability. Record task completion, misinterpretations and navigation failures separately from learning.
2. After appropriate research authorization, preregister a randomized comparison of text-only versus integrated expedition using the same content, exposure budget and assessment schedule. Use fresh, exposure-controlled assessment items. Do not change the method-condition experiment simultaneously unless the factorial design is powered for it.
3. Define return measures in advance (for example voluntary return within seven days) and a separate blinded reasoning-quality outcome. Report attrition, uncertainty, baseline differences, device/accessibility effects and item effects. Set sample size from a defensible target effect and simulation, not an arbitrary promise of significance.
4. Audit whether rewards shift users toward superficial completion, unnecessary revision, socially expected positions or repeated easy questions. Count these as potential harms, even if raw engagement rises.
5. Do not enable collection or make effectiveness claims until those observations exist. This release adds no behavioral telemetry.
