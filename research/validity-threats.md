# Validity argument and threats

The permitted launch claim is narrow: the interface displays selected responses, opportunities, and provisional rubric descriptions. No validation evidence has been collected for this instrument.

| Inference | Threat | Evidence needed | Current restriction |
|---|---|---|---|
| Response → score | Rater ideology, verbosity, dialect, hallucinated excerpts | Blind independent ratings; paired style and conclusion audits; evidence-span verification | Scores are provisional; explanations visible |
| Score → sampled skill | Prompt underspecification, NA scored zero, coaching | Opportunity audit, denominator tests, fixed assessment path | Separate assessment and exploration |
| Sample → domain | Too few items, local dependence, narrow traditions | Broad item sampling, generalizability analysis, content review | Display item counts and unassessed areas |
| Domain → general ability | Domain specificity, language and expertise confounds | Multiple domains, competing-factor models, invariance | No overall depth or intelligence ranking |
| Change → learning | Practice, response length, rater drift, regression | Alternate forms, blinded scoring, comparison groups | Describe observed revisions only |
| Learning → transfer | Repeated prompts masquerading as novel problems | Unseen tasks, changed domain/context, delayed measures | No transfer claim |
| Group comparison | DIF, nonrepresentative recruitment, accessibility | Voluntary demographics under approval; adequate subgroup precision | No population norms or inferred demographics |
| Game event → trait | XP, clicks, dwell time measure opportunity or engagement | An explicit separately validated evidence model | XP is activity only |
| Study result → causal claim | Attrition, contamination, variable AI dose | Random assignment, intention-to-treat, missing-data sensitivity | No causal claim before study |
| Interpretation → use | Stigma, gatekeeping, surveillance | Consequences review with affected people | No employment, diagnosis, admissions, or political screening |

Reliability cannot substitute for validity: raters can agree on a biased rule. Internal consistency cannot establish a single construct. High AI–human correlation does not establish absolute agreement or justify replacing human review. Rater consensus is a fallible reference, not ground truth.

Planned uncertainty is based on sampling and measurement assumptions, not an arbitrary confidence percentage. A sparse personal profile should state “limited evidence” and show counts; it should not manufacture a normal-theory interval from a handful of ordinal answers. Any later inferential interval must name its estimand, method, clustering unit, and missingness assumptions.
